# Plataforma: Bluesky

- **Slug**: `bluesky`
- **Tipo**: Social Media / Protocol (AT Protocol)
- **API Docs**: https://docs.bsky.app/docs/api/com-atproto-sync-get-blob
- **Rate Limits**: https://docs.bsky.app/docs/advanced-guides/rate-limits
  - Baseado em PDS (Personal Data Server)
  - Limits por DID, não por app
- **Políticas Relevantes**:
  - Terms of Service: https://bsky.social/about/tos
  - Community Guidelines: https://bsky.social/about/community-guidelines
  - Moderation: https://docs.bsky.app/docs/learn/moderation
- **Contato Segurança**: security@bsky.app
- **Histórico de Incidentes**:
  - #22: APP-DEN — Apelação negada para labeler de conteúdo neurodivergente
- **Notas**:
  - Arquitetura federada = rate limits variam por PDS
  - Labelers podem ser usados para moderação comunitária
  - AT Protocol permite portabilidade de identidade (DID)
  - Menos centralizado = menos capacitismo sistêmico, mas moderação inconsistente
